# Controller glyphs

"Input Prompts" icon pack by **JulioCacko** (itch.io / FAB, published 2023-06-30, updated 2025-02-03), 128x128 PNGs,
used unmodified. Subset imported here: Xbox (`xbox`; also used for Steam Deck / Steam Controller / generic XInput),
PlayStation 5 and 4 (`ps5`, `ps4`), Nintendo (`switch`, face buttons swapped because the game's A/B/X/Y are positional).

License: stated as **CC0 1.0 Universal** ("Creative Commons Zero v1.0 Universal", no attribution required) on the pack's
store page (owner-supplied screenshot, 2026-10-12). **The archive itself contains no license file**, so this is
*identified but not independently verified*; confirm against the original download page before commercial release.
Source archive: owner-provided `Source.zip` (Keyboard_Mouse, P4Gamepad, P5Gamepad, SGamepad, XGamepad).

`index.json` maps prompt tokens (`A`, `LB`, `D-Pad Up`, ...) to files per family. Used by `scripts/ui/glyphs.gd`.
Not imported (not needed by the current prompts): Xbox Menu/View/Steam glyphs (the pack's Xbox set has none: those
two prompts stay as text), stick-direction glyphs, keyboard/mouse glyphs, alternative colour/retro styles.
